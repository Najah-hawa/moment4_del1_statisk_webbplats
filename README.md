# SEE Bilförsäljning AB – Statisk webbplats (Laboration 4.1)

Detta repository innehåller den statiska webbplatsen för det fiktiva företaget **SEE Bilförsäljning AB**, skapad i HTML, CSS och JavaScript som **del 1** av uppgiften (grund inför kommande WordPress-tema i del 2).

## Bakgrund och uppdateringar inför inlämning
Jag skapade ursprungligen denna uppgift när jag läste kursen tidigare, men eftersom jag inte blev klar med moment 2 förra året har jag nu gått igenom och justerat webbplatsen så att den uppfyller kraven för del 1 och ger en bättre grund inför WordPress-arbetet. Samtliga sidor är kontrollerade och validerar utan fel.

## Publicerad webbplats
- **Live-länk:** `https://studenter.miun.se/~naha2204/DT209G/moment4-del1/index.html`

## Sidstruktur och innehåll
- `index.html` – Startsida med utvalda bilar, kommande bilar och presentation av företaget.
- `lager.html` – Översikt över tillgängliga och kommande bilar.
- `bil_info.html` – Detaljerad information om fordon och kontaktuppgifter vid intresse.
- `om.html` – Företagsbeskrivning, vision, värderingar samt presentation av personalen.
- `contact.html` – Kontaktformulär (CSS-stylat) för förfrågningar.
- `page-ai-verktyg.html` – Dokumentation av hur AI-verktyg har använts i arbetet.

## Mappstruktur
- `css/` – Stilmallar (`style.css`).
- `Bilder/` – Bilder, logotyp och favicon.
- `main.js` – JavaScript för navigation/interaktion.
- `.gitignore` – Filer och systemmappar som exkluderas från versionshantering.

## Teknik och krav
- Byggd med semantisk HTML5, CSS3 och JavaScript (ingen PHP eller externt ramverk i del 1).
- Responsiv design anpassad för olika skärmstorlekar och webbläsare.
- Huvudmeny uppbyggd med `<nav>` och `<ul>`, där styling riktas mot `<nav>` för att underlätta övergången till WordPress-tema i del 2.
- Versionshanterad kontinuerligt med Git och publicerad på GitHub.
